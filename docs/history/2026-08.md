### 2026-08-01 — Google OAuth SSO

- Implemented Feature #29 with Supabase Google OAuth through Expo Auth Session and Web Browser on native platforms, and normal browser redirect behavior on web.
- Added callback-base validation, query/fragment parsing, provider cancellation/error handling, PKCE code exchange, duplicate callback protection, and RootGate routing so callback failures remain visible.
- Added consistent same-account recovery: an existing email/password account can authenticate with email first and then link its Google identity through Supabase `linkIdentity`, with cancellation and provider failures returning to the email session.
- Added a forward profile-trigger migration that derives a new Google profile's display name from provider first-name metadata and preserves manually chosen names on later identity linking.
- Added a collapsible More → Profile editor for name and avatar changes, plus Profile-page edit controls that open that editor while collapsing Habit Targets.
- Added “Continue with Google” actions to sign-in and sign-up while preserving email/password, email verification, password recovery, guest mode, and onboarding-import gating.
- Added `expo-auth-session` and `expo-web-browser`, pure callback parser tests, README setup instructions, and roadmap status updates.
- Synchronized the local and linked Supabase migration histories: all 28 versions match, the Google profile-trigger migration was applied remotely, the remote dry run is up to date, and a read-only deployed-function check confirmed `SECURITY DEFINER` with an empty `search_path`.
- Verification: local Supabase reset applied all migrations successfully; `npm run supabase:test` passed all 140 pgTAP tests; `npm run supabase:lint` completed with only pre-existing warning-level issues in unrelated Guild RPCs; `npm run typecheck`, `npm run test:local` (27 tests), Expo dependency compatibility, and mobile-sized browser checks passed. External Google Cloud/Supabase provider configuration and device-level OAuth verification remain deployment prerequisites.
