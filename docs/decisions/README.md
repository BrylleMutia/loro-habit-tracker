# Loro Decision Records

These records contain focused product and engineering decisions extracted from the roadmap. Read only the record relevant to the current task; do not load the entire directory for ordinary implementation work.

## Records

- [`after-adventure-paths.md`](./after-adventure-paths.md) — options for progression after all Adventure Paths are complete.
- [`loot-pool-management.md`](./loot-pool-management.md) — loot-pool and catalog-management decisions.
- [`planned-feature-review.md`](./planned-feature-review.md) — assessment of previously proposed features.
- [`roadmap-conflicts.md`](./roadmap-conflicts.md) — resolved overlaps and deferred product decisions.
- [`maintenance-notes.md`](./maintenance-notes.md) — current roadmap maintenance and engineering debt notes.
- [`implementation-order.md`](./implementation-order.md) — recommended delivery sequence and dependency map.

## Source of truth

Decision records preserve rationale and historical intent. Source code, tests, migrations, generated types, and deployed configuration remain the final truth for current behavior.
